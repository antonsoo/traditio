## Operated public journeys

| Browser                | Viewports               | Actual hosted work                                                                                                                                  |
| ---------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chromium 153.0.8010.12 | 1440 x 1000; 375 x 1000 | Cases, keyboard comparison, Latin, nine displayed source pages, all three counterexample claims, native downloads, reopening, offline reload/export |

The public journey changes an ownership case, pins and compares the result,
reads _quamquam_, and hashes the actual source-image Blobs shown in the reader.
It then constructs counterexamples, checks false premises and the provincial
boundary, cites _quamvis_ in 2.51 and the period in 2.42, preserves a fixed
submission while changing the live case, and reopens the native saved argument.
The standalone casebook contains its own source pages and fonts and makes no
HTTP asset request when opened by file URL.

For the offline step, a local CONNECT proxy relays the real site's TLS traffic
unchanged. The review closes those tunnels and refuses new connections. A fresh
browser context without a worker fails to open the site, demonstrating that the
transport is actually unavailable. The previously loaded reader still reloads,
opens its retained scan, and exports the identical argument casebook. This
avoids treating a browser's offline-emulation switch as proof of worker behavior.

Each reader had the controlling `traditio-e9b21d2df854b7b3c9b4` edition and all
**21** inventory entries. All four journeys report no page/console errors or
external asset requests; the expanded argument has zero violations under the
axe WCAG 2/2.1 A/AA checks. These are bounded browser observations, not a claim
about every assistive technology or future browser storage retention.

The [machine-readable public receipt](../studies/publication/public-review.json)
contains both complete canonical inventories, browser versions, actual source
hashes, native casebook identities and the offline method. Reproduce it from a
matching build with `npm run test:public`.
